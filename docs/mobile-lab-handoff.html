Mobile Lab — WordPress Theme

เอกสารส่งมอบสำหรับ Developer & ลูกค้า · สเปกวิดีโอ Hero · เมนู · การติดตั้ง · โครงไฟล์

ธีมนี้แปลงมาจากเว็บ static ของ Mobile Lab — คงระบบดีไซน์ Digital Blue, logo hover, จุดคั่นน้ำเงิน, scroll fade-in, ตัวกรองปี และ hero เต็มจอ (วิดีโอ หรือ รูปภาพ) ไว้ทั้งหมด โดยลูกค้าแก้เนื้อหาเองได้ผ่านหลังบ้าน WordPress

เมนูด้านบน — เพิ่ม/แก้เองหลังบ้านได้

ทำด้วยระบบเมนูของ WordPress (wp_nav_menu) — ลูกค้าแก้เองได้ที่ Appearance → Menus โดยไม่ต้องแตะโค้ด:

  • เพิ่ม / ลบ / สลับลำดับเมนู · เปลี่ยนชื่อ
  • ลิงก์ไปหน้าไหนก็ได้ (Page, Post, Custom URL)
  • สร้างเมนู แล้ว assign ไปที่ตำแหน่ง Primary

ฟอร์ม & อีเมล

ฟอร์มทั้งหมด (Contact, Shop enquiry) ส่งอีเมลไปที่ nontawat@mobilelabproject.com

  • วางฟอร์มด้วย shortcode [ml_form] ในหน้า (Contact / Shop) — เปลี่ยนหัวข้อ/ปุ่มได้:
    [ml_form heading="Order / Enquiry" button="Send enquiry"]
  • มีกันสแปมในตัว (honeypot + nonce) · สไตล์ตรงตามดีไซน์ (คลาส .form .field .submit)
  • แก้อีเมลปลายทางได้ที่ constant MOBILE_LAB_FORM_EMAIL ใน functions.php
สำคัญ (deliverability): wp_mail() บนโฮสต์ทั่วไปอาจส่งไม่ถึง/เข้า junk → แนะนำติดตั้งปลั๊กอิน WP Mail SMTP เพื่อส่งเมลได้ชัวร์ · หรือใช้ Contact Form 7 / WPForms แทน โดยตั้ง recipient = อีเมลเดียวกัน

การติดตั้ง (สำหรับ Dev)

  1. บีบโฟลเดอร์ mobile-lab/ เป็น mobile-lab.zip
  2. WP admin → Appearance → Themes → Add New → Upload Theme → Activate
  3. ติดตั้ง & เปิดใช้ปลั๊กอิน Advanced Custom Fields (ACF) — Repeater (ลิงก์วิดีโอ) และ Gallery ต้องใช้ ACF PRO, ที่เหลือใช้ตัวฟรีได้
  4. Settings → Reading → ตั้ง Homepage (front-page.php จะ render News feed เอง)
  5. Settings → Permalinks → กด Save (flush rewrite rules ให้ CPT)
  6. อัปโหลดรูป/วิดีโอจริงเข้า Media แล้วกรอกเนื้อหา
