# Hero Video — Spec Brief (News & Projects)

บรีฟสเปกวิดีโอแบนเนอร์ (hero) สำหรับส่งลูกค้า/ทีมตัดต่อ และใช้เป็นข้อความกำกับในหลังบ้าน WordPress

## ใช้ที่ไหน
| หน้า | ตำแหน่ง | ความสูงที่แสดง |
|---|---|---|
| **News** (หน้าแรก) | แบนเนอร์บนสุด | ~เต็มจอ ลบแถบเมนู+footer (`100svh − 138px`) |
| **Projects** (หน้ารายละเอียดโปรเจกต์) | ใต้ header | เต็มจอ (`100vh`) |

## การแสดงผล (สำคัญต่อการถ่าย/ตัด)
- **เต็มความกว้างจอ (full-bleed)** ทุกขนาดหน้าจอ
- ใช้ `object-fit: cover` → วิดีโอ **ถูก crop ให้เต็มกรอบ** ไม่เห็นขอบดำ
  → **เก็บ subject สำคัญไว้กลางเฟรม** (safe area) เพราะขอบซ้าย-ขวา-บน-ล่างอาจโดนตัด
- เล่นแบบ **autoplay + muted + loop + playsinline** (เล่นเอง ไม่มีเสียง วนซ้ำ เล่นในมือถือได้)
- มือถือแนวตั้ง: วิดีโอ 16:9 จะเหลือเฉพาะกลางเฟรม → subject ต้องอยู่กลาง

## สเปกวิดีโอที่แนะนำ
| หัวข้อ | ค่า |
|---|---|
| **Filetype / Codec** | **MP4 (H.264)** — นามสกุล `.mp4` (มาตรฐานเว็บ เล่นได้ทุก browser) |
| **ความละเอียด** | **1920 × 1080 px** (Full HD) |
| **อัตราส่วน** | **16:9 แนวนอน** |
| **ขนาดไฟล์** | **≤ 8 MB** (แนะนำ) · สูงสุดไม่ควรเกิน **15 MB** |
| **ความยาว** | 10–30 วินาที (ตัดให้ loop ต่อเนื่องเนียน) |
| **Frame rate** | 24–30 fps |
| **Bitrate** | ~3–6 Mbps (ปรับให้ได้ขนาดไฟล์ตามเป้า) |
| **เสียง (audio)** | **ไม่ต้องมี** — ตัด audio track ออก ช่วยลดขนาดไฟล์ (เล่นแบบ muted อยู่แล้ว) |

## กรณีไม่มีวิดีโอ — อัปรูปภาพแทนได้ (Hero image)
ถ้ายังไม่มี/ไม่ต้องการวิดีโอ ให้อัป **รูปภาพขนาดเดียวกับวิดีโอ** ใช้เป็น hero แทนได้เลย —
แสดงเต็มจอ crop เหมือนกัน (subject อยู่กลางเฟรม)
| หัวข้อ | ค่า |
|---|---|
| **Filetype** | **JPG** (ถ้าต้องโปร่งใสใช้ PNG) · WebP ก็ได้ |
| **ความละเอียด** | **1920 × 1080 px** (16:9) — เท่ากับวิดีโอ · จอ retina ใช้ 2560 × 1440 ได้ |
| **อัตราส่วน** | 16:9 แนวนอน |
| **ขนาดไฟล์** | ≤ **800 KB** (แนะนำ) · สูงสุด ~1.5 MB |

**ลำดับการใช้งาน (WordPress):** มีวิดีโอ → ใช้วิดีโอ · ไม่มีวิดีโอแต่มีรูป → ใช้รูป · ไม่มีทั้งคู่ → พื้นทึบ

## Poster (รูปสำรองของวิดีโอ) — แนะนำให้มีเมื่อใช้วิดีโอ
แสดงก่อนวิดีโอโหลด / กรณี browser บล็อก autoplay (คนละอันกับ "Hero image" ด้านบน — อันนี้ใช้คู่กับวิดีโอ)
| หัวข้อ | ค่า |
|---|---|
| Filetype | **JPG** |
| ความละเอียด | 1920 × 1080 px (16:9) — เฟรมแรกของวิดีโอ |
| ขนาดไฟล์ | ≤ 300–500 KB |

## หมายเหตุ
- ปัจจุบันใช้ไฟล์วิดีโอ **ตัวเดียวกัน** ทั้ง News และ Projects (`assets/hero.mp4`) — จะแยกคนละตัวก็ได้
- (ทางเลือก) เพิ่ม **WebM (VP9)** เป็น source สำรอง ลดขนาดไฟล์ได้อีก ~30% (browser รุ่นใหม่จะเลือกใช้เอง, MP4 ยังต้องมีเป็นตัวหลัก)
- ยิ่งไฟล์เล็ก หน้ายิ่งโหลดเร็ว — hero video ควรเบาที่สุดเท่าที่คุณภาพยังดี

## แสดงสเปกนี้ในหลังบ้าน WordPress (ทำได้)
ในหลังบ้าน dev จะทำ **2 ช่อง** ด้วย **ACF**: ช่องอัปวิดีโอ + ช่องอัปรูป (theme ใช้วิดีโอก่อน ถ้าไม่มีก็ใช้รูป)
แต่ละช่องใส่ **"Instructions"** กำกับได้ ลูกค้าจะเห็นตอนอัปโหลด เช่น:

> **Hero — วิดีโอ** (ถ้ามี): MP4 (H.264), 1920×1080 (16:9), ≤ 8 MB, ไม่มีเสียง · เล่น loop อัตโนมัติ
> **Hero — รูปภาพ** (กรณีไม่มีวิดีโอ): JPG, 1920×1080 (16:9), ≤ 800 KB
> ทั้งคู่จะถูก crop ให้เต็มจอ — เก็บ subject ไว้กลางเฟรม

ทำได้หลายจุด:
1. **ACF field instructions** — ข้อความใต้ช่องอัปโหลดในหน้าแก้ไข (แนะนำ, เห็นตอนใช้งานจริง)
2. **หน้าคู่มือใน admin** — เมนู "คู่มือการใช้งาน" แสดงบรีฟนี้
3. จำกัดชนิดไฟล์ที่อัปได้ (ช่องวิดีโอ = mp4, ช่องรูป = jpg/png/webp)
