บรีฟเพิ่มเติม (เพิ่มจากงานเดิม) · เพิ่มระบบ แท็ก ให้โพส News / Press · สำหรับ Developer

เพิ่ม Tag ให้บทความ News/Press แสดงแบบ inline คั่นด้วยจุดน้ำเงิน (ตามที่เลือก) · แท็กคลิกได้ ไปหน้า tag archive

หน้าตา (Style)

TagsDOI BOYNetflixFilm2023
  • แสดงใต้เนื้อหาของแต่ละโพส
  • ตัวอักษรสีน้ำเงิน #0000FF · คั่นด้วยจุดวงกลมน้ำเงิน 4px · ตัวพิมพ์ใหญ่ letter-spacing เล็กน้อย
  • hover = ตัวขาวบนพื้นน้ำเงิน (ตามระบบดีไซน์)

สิ่งที่ต้องเพิ่มใน theme (3 จุด)

1. เปิด taxonomy post_tag ให้ CPT — ใน inc/post-types.php เพิ่มใน args ของ press/project/community:

'taxonomies' => array( 'post_tag' ),   // เปิด Tags ให้ CPT (Posts มีอยู่แล้ว)

2. แสดงแท็กในลูป News/Press — ใน front-page.php และ archive-press.php วางหลัง .entry-content (ก่อน </article>):

<?php the_tags(
  '<div class="tags-dot"><span class="lbl">Tags</span>',
  '<span class="sep"></span>',
  '</div>'
); ?>

3. CSS — เพิ่มใน style.css (ถ้ายังไม่มี):

.tags-dot{display:flex;flex-wrap:wrap;align-items:center;margin-top:2px;
  font-family:var(--mono);font-size:12px;letter-spacing:1.5px;text-transform:uppercase;color:var(--body);}
.tags-dot .lbl{margin-right:10px;}
.tags-dot a{font-family:var(--mono);color:var(--accent);text-decoration:none;padding:1px 4px;}
.tags-dot a:hover{color:#fff;background:var(--accent);}
.tags-dot .sep{display:inline-block;width:4px;height:4px;border-radius:50%;
  background:var(--accent);margin:0 8px;flex:0 0 auto;}
อ้างอิงโค้ดพร้อมใช้: ทั้ง 3 จุดนี้อยู่ใน repo แล้ว (wordpress-theme/mobile-lab เวอร์ชันล่าสุด) — ถ้าดึง repo ล่าสุดจะได้เลย · ถ้าทำต่อจากไฟล์เดิม ให้ก็อป 3 ส่วนบนไปแปะ

การใช้งาน (ลูกค้า)

  • ตอนเขียน/แก้โพส พิมพ์แท็กในช่อง Tags (ด้านขวา) — เช่น DOI BOY, Netflix, 2023
  • คลิกแท็กที่หน้าเว็บ → ไปหน้ารวมโพสที่ติดแท็กเดียวกัน (tag archive)
